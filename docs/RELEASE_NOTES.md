# 0.1.0 — Offline chat-input evidence

First alpha of a local preprocessing regression workflow, not a universal deployment certification tool.

## Included

- Explicit local HF fast-tokenizer and chat-template capture with real direct and two-stage observations.
- Strict versioned snapshots, complete named-case coverage and vocabulary-identity checks.
- Layered drift evidence, input/intent incomparability, and stable CLI exit codes.
- Dependency-free comparison and script-free offline HTML, with sensitive content hidden by default.
- Original tiny-vocabulary demo reproducing extra-special-token drift and executing its repaired path.
- UTF-8/finite JSON, actual serialized-byte budgets, exclusive output writes and input-alias protection.

## Deliberate limits

Capture is limited to the documented local text-only integration. No live model service, multimodal processing, slow/custom tokenizer, model quality, user adoption or performance claims. Trusted templates are not executed in a hostile-code sandbox. Snapshots are not cryptographically authenticated; redaction is not anonymization.

Changing a tokenizer or template can be intentional. A drift report is a review requirement, not a license to automatically rewrite model inputs or approve a new baseline.
